## 🚀 Next Steps for Going Live

### 1. App Store Connect Setup

#### A. Create Subscription Group
1. Go to [App Store Connect](https://appstoreconnect.apple.com)
2. Select your app → **Monetization** → **In-App Purchases**
3. Create a new **Subscription Group**:
   - **Reference Name**: "Fever Dream Premium"
   - **Display Name**: "Fever Dream Premium"

#### B. Create Auto-Renewable Subscription
1. In your subscription group, click **"+"** → **Auto-Renewable Subscription**
2. **Product ID**: `fever_dream_subscription_monthly` (must match code)
3. **Reference Name**: "Fever Dream Monthly Subscription"
4. **Duration**: 1 Month
5. **Price**: Select $1.99 USD tier

#### C. Set Up Free Trial
1. In subscription details → **Introductory Offers**
2. **Offer Type**: Free
3. **Duration**: 1 Month
4. **Available to**: New Subscribers

#### D. Add Localization
1. **Display Name**: "Fever Dream Premium"
2. **Description**: "Get access to all premium visual effects and future releases"

### 2. Business Setup

#### A. Agreements, Tax, and Banking
1. **Paid Apps Agreement**: Must be signed
2. **Tax Information**: Complete for your region
3. **Banking Information**: Add bank details for payments

#### B. App Information
1. **Privacy Policy**: Required (create and link)
2. **Subscription Terms**: Auto-generated by Apple
3. **App Review Information**: Add test credentials

### 3. Testing (Before Submission)

#### A. Sandbox Testing
1. **Create Sandbox Testers** in App Store Connect
2. **Test subscription flow**:
   - Sign out of App Store on device
   - Install test build via TestFlight
   - Test purchase flow with sandbox account
   - Verify free trial works
   - Test subscription cancellation
   - Test restore purchases

#### B. TestFlight Testing
1. Upload build to TestFlight
2. Test with external testers
3. Verify all subscription features work

### 8. Subscription Management

After launch, users can:
- Manage subscriptions in iOS Settings → Apple ID → Subscriptions
- Cancel anytime (keeps access until period ends)
- Restore purchases on new devices

### 9. Troubleshooting

#### Common Issues:
- **"Product not found"**: Product ID mismatch between code and App Store Connect
- **"Cannot connect to iTunes Store"**: Use sandbox tester account
- **Subscription not working**: Check agreements are signed in App Store Connect

#### Testing Commands:
```swift
// Force refresh products
storeManager.loadProducts()

// Check subscription status
print("Has subscription: \(storeManager.hasSubscription)")

// View purchased products
print("Purchased: \(storeManager.purchasedProducts)")
```
